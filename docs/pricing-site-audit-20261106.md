# ホーム・FAQ・単発料金の全体点検（2026-11-06）

## 新規受付の確定内容

- 初回お試し：ショート動画1本5,000円（税込）、ロング動画1本15,000円（税込）。初回限定。尺、素材量、編集範囲、修正、撮影の有無、納期・追加費用は個別相談。通常と同一内容とは断定しない。
- 通常：ショート1本11,000円（税込・30秒以内）、ロング1本27,500円（税込・7分以内、素材30分以内・1カメラ、サムネイル1枚付き）。超過尺は個別見積もりで、旧料金の時間刻みを自動適用しない。
- 月額料金・繰越・無料特典・支払・最低2か月／以後月次自動更新・交通費は直前の承認内容を維持。

## 修正した不整合

ホームの旧月額スタンダード3万円と、通常ショート5,000円の紹介、FAQの旧単発料金を置換。料金表・単発案内・問い合わせページ・利用条件も同じ新規受付料金へ統一。ホームの月額案内はフッター後の追加ブロックから料金セクションへまとめた。

FAQには無料特典、撮影超過、繰越、交通費、修正、支払・更新、SNS対象媒体・投稿数の数え方を掲載。元定義 `monthly-pricing.js` と同じ文章で反映。

新規単発書類は `current-edit-pricing.js` と料金版 `2026-11-06-trial` を使用。初回確認を必須にし、お試し選択時に完成尺・修正回数の既定値をクリアする。通常の超過尺は個別書面で見積もり、旧追加単価では計算しない。

旧Googleフォームを現在の受付と記載していたプライバシー案内と相談導線を実装に合わせて訂正。新規制作データの保管期間は個別契約で確認し、旧契約の条件は維持する。

## 旧資料・既存契約の保持

`edit-pricing.js` の旧計算と2026-11-01版の編集範囲、無版データの旧料金、`legacy-contract-terms-20261024.js`、既存PDFのバイナリは変更しない。新規通常／お試しに旧キャンセル料金や旧修正期限等を自動適用しない。政治・選挙関連の書類例は旧料金の履歴資料であることを表全体の前に明記した。
