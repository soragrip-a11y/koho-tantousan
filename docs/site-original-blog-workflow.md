# 広報担当さん｜公式サイト原本型ブログ運用

## 掲載方針（2026-10-24）

- 今後の地域ニュースの**原本は https://local-koho.com/** に置く。
- 対象は **君津市・船橋市・千葉県全体**。1日1回まとめて調査し、各地域から最大1本（最大3本）。確かな一次情報がない日は無理に記事を作らない。
- noteとXは原本への案内・要約用。現存するnote-originの19記事を無断で改稿・消去しない。
- SEOを考慮するが、Googleの登録・順位は保証しない。掲載後にSearch Consoleでインデックス状況と検索クエリを確認する。
- ローンチ直後は**下書き保存→人間の確認→公開**。無人・無承認の公開は行わない。
- AIの作業は一次情報の収集・比較・要約・執筆・検証に限定し、毎回のHTML生成やタグ・サイトマップ更新はコードが担当する。

## 地域ニュースを選ぶ際の基準
1. 一次資料（県・市公式サイト、実施主体の公式発表など）が存在し、記事と直接一致している。
2. 読者が取れる具体的な行動（申込・確認・注意・申請・利用）がある。
3. 検索意図に沿う「地域名＋テーマ＋条件・期限・金額」などのキーワードを自然に含む。
4. 日付や金額・対象・締切・会場・電話番号は原典に照合し、確認日を記録する。
5. 同一サイトの記事との重複、失効した告知、リスクのある断定を防ぐ。
6. 目安は1,500〜2,500字だが薄い水増しはしない。出典リンク・本文見出し・結論先出し・必要ならFAQを備える。

## ソースファイルと公開制御

- `content/note-articles.json` — 過去の許可済みnote転載記事（従来どおり）。
- `content/site-articles.json` — **承認・公開済みの新規公式サイト原本記事だけ**を保存する公開リポジトリ内の一覧。初期状態は空配列。未承認下書きは保存禁止。
- `scripts/render-blog.mjs` — 旧記事を再生成した後、公式サイト原本の記事も生成する。
- `scripts/render-original-blog.mjs` — 入力検査、HTML生成、BlogPostingの構造化データ、記事一覧・sitemapの更新。
- `npm run sync:blog` — ローカルに保存された内容のみから公開ファイルを再生成する。外部ニュースを自動取得しない。
- `.github/workflows/pages.yml` — `npm ci`→`npm run sync:blog`→`npm test` を通った場合だけGitHub Pagesへ公開する。

## 公開手順と安全確認
1. 一次資料を読み、タイトル・メタ説明・本文・照合済みの出典と日付を用意する。
2. **下書きは非公開Google Driveフォルダ「広報担当さん_ブログ下書き（非公開）」に保存する。** GitHubリポジトリはpublic（公開）なので、`status: draft`であってもGitHubにコミットすると誰でも読める。どのブランチ・Issue・PRにも下書きを入れない。
3. 人間が全文・確認日・SEO・地域区分・重複を確認し、公開について明示承認する。
4. **承認後に限り**、公開記事データを `status: "published", approved: true` として `content/site-articles.json` に登録してコミットする。CIはdraft混入を検知したら公開を停止する。
5. Pagesの自動テストが成功した後、記事HTML、一覧・サイトマップを確認する。
6. noteとXには要約と公式サイトURLを載せ、リンクから誘導する。
7. Search Consoleのページ検査・サイトマップ提出・検索結果の表示回数を確認する。
