# ブログと note・X の導線

本文は https://note.com/koho_tantousan 、X は https://x.com/koho_tantousan で記事を紹介します。Web は `dist/blog.html` の短い紹介と一覧リンクです。トップのメニュー・末尾・フッターから入れます。既存の他ページ、料金やフォームは変更していません。

## 更新手順

1. Node.js 22 以降で `npm ci --ignore-scripts`、`npm run sync:blog` を実行します。OS の信頼済み証明書が必要な環境では `node --use-system-ca scripts/sync-blog.mjs` を使用します。TLS 検証は無効にしません。
2. `git diff -- dist/blog.html` を確認します。RSS の最新12件までをタイトル・公開日・冒頭120文字以内で取り込みます。日付がない・不正な場合は日付を出しません。画像・本文全体・埋め込みは使いません。紹介は自動要約ではなく冒頭の抜粋なので、必要なら結論がわかる短い要約に手直ししてください。
3. 各記事本文を確認し、君津・木更津・袖ケ浦・船橋の地域ニュースであること（政治経済・補助金も事実ベースで対象）、個人的な政治意見や賛否を含まないこと、出典、冒頭の結論をレビューします。速報は行わず、記事0件の日も無理に作りません。宣伝文面は相談段階のため記事本文への誘導は追加しません。RSS 自体には編集方針への適合を判定する機能がありません。範囲外の記事は一覧から除きます。次の同期で上書きされるため毎回レビューが必要です。
4. `npm test` と表示確認後、公開許可を得てから main に反映します。main の更新は既存 GitHub Pages ワークフローで公衆公開されます。

認証・有料サービス・外部 RSS プロキシ・スケジュール実行は追加していません。閲覧時の外部 RSS リクエストもありません。**手動で同期・レビュー・反映するまで一覧は変わりません。** note の公開状況は note リンクから確認できます。取得失敗時は既存 HTML を保持し、記事0件が正常に確認できた場合だけ空状態へ更新します。
