## 最短の実演手順
1. 同じスマホの同じブラウザーで投稿体験URLを開く。
2. 架空の写真、見出し、短い文章を入れる。
3. 「保存して客向けプレビューを見る」を押す。写真と文章が表示される。
4. 再読込して残ることを確認。必要なら投稿体験へ戻り、売り切れ・終了・編集を試す。
5. 終了後は下部の「デモをリセット」で初期状態に戻す。

保存はそのブラウザーだけ。Safari/Chrome/LINE内ブラウザーを途中で切り替えると共有されない。他の人や端末へ公開・送信しない。実データ・個人情報・秘密は入力しない。本番管理画面でもログイン画面でもない。

## 実装範囲
投稿体験は写真（JPEG/PNG/WebP、2MB以下、最大960pxへ縮小）、見出し40文字、本文180文字、期限を入力可能。保存後は自動で客向けプレビューへ移動。編集・個別売り切れ・終了を体験できる。過去の期限は終了表示。同じブラウザーで再読込して保持。全体リセットに対応。

「行ったよ」は日本時間の1日1回、本人ブラウザーだけの既存簡易デモ。実人数・来店証明・全利用者集計ではない。順位なし。B〜E店は表導線・店舗ページから除外。店舗IDで分けるモデルは将来用に維持。

本物の管理履歴・利用者データ・秘密を静的コードに含めない。投稿体験では操作履歴を作らない。保存するのはユーザーがこのブラウザーで入力した架空の投稿内容と自己申告だけ。以前の管理プレビューはリポジトリ外のローカルに残し、公開物に入れない。CSPで connect-src none / form-action none を設定し、投稿内容の通信送信も遮断。HTMLは noindex/nofollow/noarchive。既存本番ページ・フォーム・sitemapは変更しない。

post-model.js はローカル投稿の保存・検証、model.js は店舗モデルと自己申告、app.js は画面表示。実際の店舗運用には正規認証・店舗別サーバー権限・共有DB・画像保存・サーバー期限判定が必要で、未実装。ドメイン変更だけでは本番化しない。API資格情報、契約、OAuth、課金は追加していない。
