# 君津中富店：店舗情報と投稿

- お客さん用：https://local-koho.com/demo/stores/
- 店員さん用：https://local-koho.com/demo/stores/staff.html

## 現在の仕組み
投稿・写真はSupabaseに共有保存。店舗が公開設定なら匿名のお客さんにも表示され、非公開なら権限のある店員さんだけが確認できる。公開設定はこの画面から変更しない。
店員はメール・パスワードでログインし、サーバー側の店舗所属確認後に操作する。ログインはメモリー内だけで、再読込時は再ログインが必要。客画面に管理リンクや入力欄はない。旧hashでも客画面のまま。

写真は任意。写真→文章→確認→投稿。投稿・編集後24時間で終了表示になり、自動削除しない。編集は同じ投稿を更新し期限を延長する。写真変更・取り外しだけでは以前の画像や監査記録は消さない。
削除には確認が入り、対象投稿と専用の現用・旧画像を削除する。他投稿が参照する画像、非公開の監査記録（本文・画像パス）は残る。画像削除はStorage APIで行い、途中失敗は同じ削除処理を再開できる。

客画面の「更新」は表示情報を再取得する。通信中は無効化し、連打をまとめる。失敗時は古いカードを消し、失敗を明示する。自動ポーリングはない。画面復帰時等の従来の再取得は維持。
「いいね」は端末内のみのデモ。店舗へ届かず共有集計しない。日本時間で1日1回。KPIは未実装。

JPEG/PNG/WebP・10MB以下を最大960pxのJPEGへ変換する。実機カメラは端末対応に依存。既存の端末内デモ投稿を自動アップロードしない。
検索への追加は行わずnoindexを維持。チェーンロゴは使用しない。認証・権限・公開設定の変更は今回行わない。
