# 中富店1店舗・らくらく投稿体験

実演開始: https://local-koho.com/demo/stores/#post
入口: https://local-koho.com/demo/stores/
客向けプレビュー: https://local-koho.com/demo/stores/#store/nakatomi

## 当日の最短手順
1. 同じスマホの同じブラウザーで「実演開始」を開く。
2. 「写真を撮る」か「スマホの写真を選ぶ」。写真なしでも次へ進める。
3. 伝えたいことをひとこと書き、「内容を確認する」。
4. 写真と文章を確認し「このスマホに載せる」。客向けの見本へ移動する。
5. 再読込して残ることを確認。「このお知らせを変更」から書き直し・売り切れ・取り下げを試せる。
6. 最後は下部の「デモをリセット」で初期状態に戻す。

Safari/Chrome/LINE内ブラウザーを途中で切り替えると共有されない。保存は同じブラウザー内だけ。他の人へ公開・送信しない。架空データだけで実演し、実データ・個人情報・秘密を入力しない。

## 入力画面
写真→ひとこと→確認の3段階。1画面1作業を基本に、見出し30〜32px、本文22px、入力26px、主要ボタン24〜26px・高さ80px以上。大きな戻る・取消ボタンを用意。取消・売り切れ・取り下げは確認後に実行。保存連打でも重複投稿しない。

日時の入力・管理集計・順位を主画面に置かない。投稿は自動で24時間後に終了する。書き直して載せ直すと24時間に更新。写真は任意、JPEG/PNG/WebP・10MB以下を最大960pxへ縮小。撮影の起動方法は端末・ブラウザーの対応に依存する。カメラ用入力に capture=environment、画像選択用入力にはcaptureを付けず、選べる構成。

## 境界と本番の不足
本物の管理履歴・利用者データ・秘密は公開コードに含まない。投稿体験で操作履歴は作らない。以前の管理プレビューはリポジトリ外にあり公開しない。CSPで connect-src none / form-action none を設定。HTMLは noindex/nofollow/noarchive。既存本番ページ・フォーム・sitemapは変更しない。

post-ui.js が3段階UI、post-model.js がローカル保存と検証、model.js が店舗モデルと自己申告、app.js が画面遷移。実運用に必要な正規認証・店舗別サーバー権限・共有DB・画像保存・サーバー期限判定は未実装。ドメイン変更だけでは本番化できない。契約・API資格情報・OAuth・課金は追加していない。
