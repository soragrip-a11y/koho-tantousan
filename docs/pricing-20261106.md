# 新規料金の適用（2026-11-06）

実写月額は税込55,000円・88,000円・132,000円・165,000円。プレミアム165,000円の制作枠は132,000円分で、差額を撮影・編集枠へ換算しない。価格・編集範囲・運用範囲・繰越・支払条件の定義は `dist/monthly-pricing.js`。

新規フォームには `monthly55000` 等の新しいIDのみを表示する。旧 `standard` / `companion` / `premium` / `single` の計算と `legacy-contract-terms-20261024.js` は履歴互換のため残し、既存契約や見積を変えない。新しい月額PDFは `monthly-document.js` で作成する。

通常の制作枠の本数は同額範囲内で組み替え可能。無料特典と有効な繰越残額は通常枠へ重ねて入力せず、月ごとに利用元の月・期限・残額・利用内訳を確認する。追加明細は残額を超えた分のみ。期間全体へ同じ繰越額を自動適用する計算は行わない。

有料枠は翌々月末まで有効。解約時は有効な枠を契約終了日まで利用でき、終了後は失効。返金は契約内容に応じて別途明記し、一律返金不可にしない。月額は当月分を前月末までに前払い、初月支払日は契約時に別途決定。

アニメーションCMは30秒以内33,000円（税込）〜へ置換。新規フォームは `adCmVersion: 20261106` を付ける。版がない過去のCMデータは55,000円の旧基準・旧範囲を保持する。新CMの制作詳細・修正・追加条件・支払いは個別合意し、旧CMのAIナレーション・修正2回等を自動継承しない。

素材支給の単発編集は別メニューとして従来料金を維持。月額枠の換算単価を単発編集へ自動適用しない。旧PDF見本は履歴資料と明示し、上書きしない。

プレミアムの対象はInstagram・YouTube・TikTok。媒体ごとに1投稿と数え、同じ動画を3媒体へ投稿すると3投稿分となる。素材や納期の細部、追加費用の支払期限などは契約時相談。契約作成だけで合意済みとはしない。
