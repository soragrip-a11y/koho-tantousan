# 新規取引の書類PDF

入口は `dist/contract.html`。依頼区分を必ず選択し、未選択や区分のない旧データを一般事業扱いしません。一般事業の場合のみ、契約書・見積書・請求書を選び、合意した期間、動画本数、追加撮影、追加単価、実費を入力します。一般事業の契約書には利用条件14節と署名欄、見積書には期間総額、請求書には指定月の金額を記載します。作成だけで契約は成立しません。

料金は税込。スタンダード30,000円・ショート6本、伴走型80,000円・ショート6本、プレミアム120,000円・ショート8本とロング2本。伴走型・プレミアムの月2回撮影は二重加算しません。スタンダードの追加半日撮影は17,000円。初回お試しはショート5,000円×3本以上・初回半日撮影15,000円です。半日は現地3時間です。

TikTokは同じ動画の投稿のみ月15,000円。月額の追加動画・伴走型やプレミアムの追加撮影は合意済み単価を明示入力し、空欄を無料扱いしません。お試しの追加撮影やロング単発は個別相談で、このフォームの自動計算対象外です。

「1回のみ」の費用は第1月の請求だけ、「毎月」は各月に反映します。期間総額は一括前払請求額ではありません。最低期間・自動更新は設定せず、継続は別途合意します。初月・単発は着手前、以降は当月末。請求日・銀行営業日・振込先は発行者が確認して入力します。未確定実費は総額に含めません。

入力情報は端末内で処理し、送信・保存しません。受託者住所は空欄で、契約時に記入します。既存の署名済み契約を更新する機能はありません。口座案内・署名回収・保存・送付は別途行います。

- `contract-core.js`: 共通計算・入力検証
- `contract.js`: フォーム・Blobダウンロード
- `contract-pdf.js`: 3種類の書類・折り返し・改ページ。日本語の欠字を防ぐためフォント全体を埋め込みます。
- `contract-terms.js`: `terms.html` の全文スナップショット。`npm run sync:terms` で同期。
- `dist/downloads/sample-*.pdf`: 架空データの公開見本。追加単価はサンプルの個別合意例です。

検証は `npm test`（Node.js 22以上）。PDF例は `tmp/pdfs/` に生成されます。Popplerで全ページを描画し日本語・金額・改ページを確認してください。実ブラウザーの保存・表示は別途検証します。実機iPhone Safariは未確認です。

main更新で既存GitHub Pagesがdistを公開します。秘密鍵・外部PDF APIは不要です。

## 2026年10月24日 受託条件・AI利用方針

政治活動関係／選挙関係・判断未了は、通常プランを自動適用せず「受託前確認票（受託未確定）」のみを生成します。金額・包括業務・署名欄は出しません。目的と作成日と確認チェックを必須とし、未確認項目は「未確認」と表示します。専門家確認の記録を入力しても契約・見積・請求へ自動昇格しません。必要な確認後、個別の業務範囲・条件を書面で合意します。

共通文言は `acceptance-policy.js`、公開利用条件は `terms.html` と `contract-terms.js`。`node scripts/generate-policy-documents.mjs` は今後用の6見本・3ガイドを日付付きで生成します。旧PDFや締結済み契約は上書きしません。発注書・領収書の生成テンプレートは本リポジトリにはありません。副サービスの個別見積もりも既存動画プランの計算へ混在させません。
