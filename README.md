# koho-tantousan
広報担当さん｜発信したい人のための動画制作・運用支援

公開URL: https://local-koho.com/

`dist/` が公開対象です。`main` の更新で GitHub Pages に自動反映されます。

## デザインの基本設定

2026-10-09にデジタル庁デザインシステムの基本デザインを参考に、既存デザインのCSSを調整しました。
https://design.digital.go.jp/dads/foundations/

- 本文・UIは原則1rem、補助情報は0.875rem。ブラウザ標準16px時に16px・14pxとなります。
- 余白は8pxを基準に、16・24・32・64px相当の相対単位を使用します。
- ブランドのオレンジは装飾に使用し、文字には濃いオレンジを使用します。
- 本文リンクに色と下線、フォーカスに黄色と黒の二重の目印を設定します。
- ボタンと入力欄の高さは48px以上とします。

独自サイトへの部分的な適用であり、デジタル庁の公式サイト、認定、またはアクセシビリティ規格への完全準拠を示すものではありません。

## 2026-10-20 料金・書類の更新
スタンダード月30,000円（ショート6本・編集納品）、伴走型月80,000円（ショート6本）、プレミアム月120,000円（ショート8本＋ロング2本）。伴走型・プレミアムは月2回の現地半日撮影と企画・YouTube投稿・月次振り返りを含みます。税込、交通費別途。初回お試しはショート5,000円×3本から、初回半日撮影15,000円。通常のスタンダード撮影は17,000円／回。TikTok同一動画投稿は月15,000円追加。

料金シミュレーションは廃止。旧URLは料金ページへ移動します。プラン比較表は従来の横並び表示です。スマートフォンでは横スクロールで確認できます。

## 契約書PDF作成

`contract.html` に契約・見積・請求書フォームを追加。顧客・契約情報、動画本数、撮影、事前見積もり済みの追加費用を入力し、署名欄を残した日本語PDFを端末内で生成します。

詳細・導入・検証手順は [docs/contract-generator.md](docs/contract-generator.md) を参照してください。料金シミュレーターは復活させていません。

## 配布書類PDFの更新

`downloads/document-guide.pdf` の請求例は `dist/expenses-guide.html` の請求書サンプルを基準にします。HTML更新後は `python3 scripts/generate-document-guide.py`（ReportLabが必要）で再生成し、2ページの表示と公式資料リンクを確認してください。スクリプトは明細と合計の一致を検証します。

問い合わせフォームはJavaScriptの準備完了まで無効です。ローカルのみでメール文を作成する処理が使えない場合に、入力内容をURLへ送信しないための対策です。`npm test` で問い合わせの模擬動作、サイト内リンク、契約計算・PDFを検証できます。

## 地域ニュースの原本型ブログ（2026-10-24）
未公開記事は非公開のGoogle Drive「広報担当さん_ブログ下書き（非公開）」に保存し、公開GitHubには保存しません。本人が記事全文を確認して明示承認した後に限り、`content/site-articles.json` に `status: published`・`approved: true` として登録し、`scripts/render-original-blog.mjs` でWebページ・SEOメタ情報・記事一覧・サイトマップを生成します。従来のnote転載19記事は維持します。公開前に `npm test` を実行します。運用方法は [docs/site-original-blog-workflow.md](docs/site-original-blog-workflow.md) を参照してください。
