## デザインの基本設定

2026-10-09にデジタル庁デザインシステムの基本デザインを参考に、既存デザインのCSSを調整しました。
https://design.digital.go.jp/dads/foundations/

- 本文・UIは原則1rem、補助情報は0.875rem。ブラウザ標準16px時に16px・14pxとなります。
- 余白は8pxを基準に、16・24・32・64px相当の相対単位を使用します。
- ブランドのオレンジは装飾に使用し、文字には濃いオレンジを使用します。
- 本文リンクに色と下線、フォーカスに黄色と黒の二重の目印を設定します。
- ボタンと入力欄の高さは48px以上とします。

独自サイトへの部分的な適用であり、デジタル庁の公式サイト、認定、またはアクセシビリティ規格への完全準拠を示すものではありません。
